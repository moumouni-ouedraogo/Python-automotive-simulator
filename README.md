
# Python Automotive Simulator

## Description
A simple Python simulation created to practice fundamental programming concepts (loops, conditions, lists). This program simulates an Electric Vehicle (EV) trip, calculating battery consumption, simulating weather conditions for emergency braking, and monitoring engine temperature based on driving modes.

## Features
*   Calculates remaining battery percentage based on distance.
*   Simulates weather conditions and triggers emergency braking alerts.
*   Monitors engine temperature based on driving mode (Eco, Sport, Normal).

## Technologies Used
*   Python 3

## How to run
1. Clone this repository.
2. Open the terminal and navigate to the project folder.
3. Run: python main.py
